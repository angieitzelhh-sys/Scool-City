# SCHOOL CITY - ASSETS DIRECTORY

Esta carpeta contiene los recursos de School City:
- `/characters/`: Retratos y avatares (generados de forma nativa e inline mediante SVG y CSS por la arquitectura limpia del juego).
- `/backgrounds/`: Fondos temáticos de las 26 pantallas (renderizados mediante capas de degradados CSS y parallax procedural).
- `/items/`: Iconos e ilustraciones de objetos, potenciadores, cuadernos y medallas.
- `/icons/`: Iconografía de interfaz para HUD, dock y modales.
- `/audio/`: Motor acústico procedural Web Audio API autónomo (no requiere archivos externos .mp3 ni dependencias de red).
